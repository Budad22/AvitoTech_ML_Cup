# CatBoost baseline Булата

Ветка: `bulat/catboost-baseline`. Каталог содержит только код, конфигурации и небольшие отчёты этого метода; модели и предсказания находятся в игнорируемой папке `runs/catboost/`.

Первый baseline — CatBoostRanker с YetiRank, пять исходных нормализованных числовых признаков f1–f5 и категория. Category_id передаётся как категориальный признак, one_hot_max_size=64 охватывает текущий словарь. Никаких ID, pos, embedding_idx, target, истории или эмбеддингов во входах. Дополнительное масштабирование числовых признаков не выполняется.

Обучение на CPU: 200 деревьев максимум, depth=6, learning_rate=0.1, seed=42, 8 потоков. Ранняя остановка после 30 итераций без улучшения; лучшая модель выбирается по полному NDCG, а не @30. Выбор checkpoint и итоговая оценка используют полную val; независимая от выбора checkpoint оценка не заявляется.

## Запуск

По умолчанию выполняются только обучение и оценка val, без чтения test и создания submission. Флаг `--make-submission` используется только по явной команде владельца. Ранее созданные файлы и метрики ниже — исторические артефакты.

Из корня репозитория:

```bash
.venv/bin/python -m pip install -r catboost/requirements.txt
.venv/bin/python catboost/baseline.py \
  --data artifacts/prepared-v1 \
  --output runs/catboost/EXP-015-r01
```

Исходные данные предварительно подготавливаются [общим загрузчиком](../docs/DATA.md). Скрипт отказывается перезаписывать существующий run: укажите новый run-ID. Можно передать другой JSON через `--config`.

Текущий train — 24 592 ленты / 1 925 512 кандидатов, четыре из 512 исходных файлов. Val используется полностью: 14 423 ленты / 1 389 971 кандидат. Это первый результат на подвыборке, а не обучение на полном train. Для такого baseline не требуются отсутствующие локальные матрицы эмбеддингов train/test.

## Артефакты

- `model.cbm`: лучшая модель.
- `val_predictions.parquet`: оценки полной val для сравнения и будущих ансамблей.
- `submission.parquet`: все 2 904 806 кандидатов test, колонки feed_id:int32, item_id:int32, score:float32.
- `config.json`, `result.json`: конфигурация, версии, хеши, метрики, время и история качества обучения.

Оценка NDCG реализует официальные пессимистичные ничьи и равный вес лент; полный NDCG независимо проверяется `catboost.utils.eval_metric`. Итоговый файл проверяется на точное покрытие шаблона, типы, уникальность ключей и конечность score. Низкий score — допустимая оценка, преобразовывать его в вероятность не требуется.

Загрузите `submission.parquet` в разделе решений соревнования. Результат Public появляется после обработки организаторами; его нельзя получить из локальных данных. До отправки проверьте общий лимит пяти попыток команды за день. Baseline самостоятельно ничего не отправляет на ODS.

## История категорий: EXP-016-r01

Три новых признака — доля категории кандидата в последних 16/64/256 событиях, плюс маска пустой истории. Деление на фактическое число событий окна; для пустой истории доли равны нулю. Повторные события и код категории 0 сохраняются. Матрицы эмбеддингов не требуются.

```bash
.venv/bin/python catboost/baseline.py \
  --feature-config catboost/configs/history_categories.json \
  --output runs/catboost/EXP-016-r01
.venv/bin/python catboost/compare_runs.py
```

Без `--feature-config` набор входов остаётся исходным. Существующие каталоги запусков не перезаписываются. `compare_runs.py` сравнивает сохранённые прогнозы на одинаковых ключах val, проверяет совпадение данных и модельных параметров, сохраняет парную разницу, срезы и bootstrap по пользователям в `comparison.json` нового запуска.

При тех же четырёх train-файлах и модельном конфиге получен полный val NDCG **0,3321577218**, разница к baseline **−0,0012953784**. Выбраны 98 деревьев, обучение 43,49 с, test-инференс с признаками/записью 1,64 с, пиковый RSS 1,38 GiB. На истории длины 256 есть диагностический прирост, на более короткой — ухудшение. Это один seed и checkpoint, выбранный на полной val; устойчивый эффект не установлен. Вариант не принят в baseline, test NDCG для него не измерен.

Модель и прогнозы сохранены отдельно в `runs/catboost/EXP-016-r01/`; отчёт: [results/EXP-016-r01.json](results/EXP-016-r01.json). Последующая проверка на увеличенном train описана ниже; прежний отрицательный результат сохраняется.

## Повтор на увеличенном train: историю оставляем

Train расширен до 16/512 равномерно выбранных файлов, включая исходные четыре: 98 428 лент, 7 706 340 кандидатов. Это по-прежнему подвыборка. Val/test не изменились. Данные подготовлены отдельно в `artifacts/prepared-train16-v1`; контроль и вариант с историей используют один модельный конфиг и seed=42.

| Train-файлы | Без истории, val NDCG | С историей, val NDCG | Δ истории |
| --- | --- | --- | --- |
| 4 | 0,3334531002 | 0,3321577218 | −0,0012953784 |
| 16 | 0,3338809516 | **0,3355296104** | **+0,0016486588** |

На 16 файлах история улучшила общее качество и диагностические срезы по длине истории, включая пустую историю. Прирост есть на обоих основных днях val. Bootstrap по пользователям даёт диагностический 95% интервал Δ [+0,00030413; +0,00307856]; он не учитывает выбор checkpoint и разброс seed. Историю оставляем как лучший текущий локальный вариант; test обоих новых запусков пока не измерен.

Воспроизведение из исходного состояния (каталоги назначения должны отсутствовать):

```bash
python3 scripts/expand_train.py --shards 16
.venv/bin/python -m recsys_data \
  --data data/train16/competition --output artifacts/prepared-train16-v1 \
  --allow-missing-embeddings
.venv/bin/python -u catboost/baseline.py \
  --data artifacts/prepared-train16-v1 --output runs/catboost/EXP-017-r01
.venv/bin/python -u catboost/baseline.py \
  --data artifacts/prepared-train16-v1 \
  --feature-config catboost/configs/history_categories.json \
  --output runs/catboost/EXP-016-r02
.venv/bin/python catboost/compare_runs.py \
  --data artifacts/prepared-train16-v1 \
  --control runs/catboost/EXP-017-r01 --treatment runs/catboost/EXP-016-r02
```

Загрузчик сверяет ETag официального архива, докачивает 12 файлов с CRC-проверкой и переиспользует неизменяемые исходные файлы через hard links. Подготовка проверена точным восстановлением всех исходных колонок 144 shard; отчёт: `reports/preparation_train16.json`.

Контроль: [results/EXP-017-r01.json](results/EXP-017-r01.json). История: [results/EXP-016-r02.json](results/EXP-016-r02.json). Сохранённый submission варианта train16: `runs/catboost/EXP-016-r02/submission.parquet`; файл проверен на 2 904 806 строк и точное покрытие шаблона, автоматически не отправлялся. Модели, прогнозы и логи сохранены отдельно; исходные запуски не перезаписаны.


## Cosine поверх истории: EXP-018-r01

Вариант с заметным приростом от cosine на **четырёх** train-файлах — **val NDCG 0,3519504563**. При сохранении истории категорий и прежних параметров добавлены cosine user/item и маска его определённости. К контролю с историей на тех же данных (EXP-016-r01) Δ=**+0,0197927345**; к исходному baseline без истории — **+0,0184973561**. Это один seed и checkpoint, выбранный на полной val; test не оценивался.

```bash
.venv/bin/python -u catboost/baseline.py   --data artifacts/prepared-v1   --feature-config catboost/configs/history_cosine.json   --output runs/catboost/EXP-018-r01
.venv/bin/python catboost/compare_runs.py   --data artifacts/prepared-v1   --control runs/catboost/EXP-016-r01 --treatment runs/catboost/EXP-018-r01
```

Cosine требует полных матриц только train/val; lookup использует матрицу своего split. Нет вектора или нулевая норма — score=0, valid=0; определённый нулевой cosine имеет valid=1. Векторы переводятся в float32 до арифметики. Train-матрица скачана и CRC проверен; без feature-config или без user_item_cosine набор входов прежний.

Подготовка/загрузка признаков заняла 109,88 с, обучение 34,71 с, весь запуск 145,24 с; выбраны 68 деревьев, пиковый RSS 3,32 GiB. Улучшение есть на обоих основных днях и всех срезах длины истории; на нулевом user-векторе (205 лент) Δ=−0,00219451. Подробности: [results/EXP-018-r01.json](results/EXP-018-r01.json) и [catboost_exp.md](../catboost_exp.md).

Модель и val-прогнозы: `runs/catboost/EXP-018-r01/`. Test не читался, submission не создавался.


## Контекст ленты: EXP-019-r01

Поверх истории и cosine добавлены только пять процентилей f1–f5 внутри текущей ленты. Формула midrank: (число меньших значений + половина числа равных) / размер ленты. Равные значения получают одинаковый процентиль, константная лента — 0,5. Метки и случайный порядок кандидатов не используются.

```bash
.venv/bin/python -u catboost/baseline.py   --data artifacts/prepared-v1   --feature-config catboost/configs/history_cosine_context.json   --output runs/catboost/EXP-019-r01
.venv/bin/python catboost/compare_runs.py   --data artifacts/prepared-v1   --control runs/catboost/EXP-018-r01 --treatment runs/catboost/EXP-019-r01
```

Полный val NDCG **0,3521669947**, Δ к cosine без контекста **+0,0002165383**. Bootstrap-интервал Δ [−0,00171056; +0,00210045] включает 0; на пустой/короткой истории есть ухудшение. Надёжное улучшение не установлено, вариант сохранён отдельно для последующего сравнения. Данные — те же 4 train-файла, параметры не менялись; checkpoint выбран на полной val, один seed.

Подготовка/загрузка 102,74 с, обучение 42,87 с, всего 146,31 с; 91 дерево, пиковый RSS 3,40 GiB. Отчёт: [results/EXP-019-r01.json](results/EXP-019-r01.json). Артефакты: `runs/catboost/EXP-019-r01/`. Test не читался, submission не создавался.
