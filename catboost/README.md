# CatBoost baseline Булата

Ветка: `bulat/catboost-baseline`. Каталог содержит только код, конфигурации и небольшие отчёты этого метода; модели и предсказания находятся в игнорируемой папке `runs/catboost/`.

Первый baseline — CatBoostRanker с YetiRank, пять исходных нормализованных числовых признаков f1–f5 и категория. Category_id передаётся как категориальный признак, one_hot_max_size=64 охватывает текущий словарь. Никаких ID, pos, embedding_idx, target, истории или эмбеддингов во входах. Дополнительное масштабирование числовых признаков не выполняется.

Обучение на CPU: 200 деревьев максимум, depth=6, learning_rate=0.1, seed=42, 8 потоков. Ранняя остановка после 30 итераций без улучшения; лучшая модель выбирается по полному NDCG, а не @30. Выбор checkpoint и итоговая оценка используют полную val; независимая от выбора checkpoint оценка не заявляется.

## Запуск

Из корня репозитория:

```bash
.venv/bin/python -m pip install -r catboost/requirements.txt
.venv/bin/python catboost/baseline.py \
  --data artifacts/prepared-v1 \
  --output runs/catboost/EXP-015-r01
```

Исходные данные предварительно подготавливаются [общим загрузчиком](../docs/DATA.md). Скрипт отказывается перезаписывать существующий run: укажите новый run-ID. Можно передать другой JSON через `--config`.

Текущий train — 24 592 ленты / 1 925 512 кандидатов, четыре из 512 исходных файлов. Val используется полностью: 14 423 ленты / 1 389 971 кандидат. Это первый результат на подвыборке, а не обучение на полном train. Для такого baseline не требуются отсутствующие локальные матрицы эмбеддингов train/test.

## Артефакты

- `model.cbm`: лучшая модель.
- `val_predictions.parquet`: оценки полной val для сравнения и будущих ансамблей.
- `submission.parquet`: все 2 904 806 кандидатов test, колонки feed_id:int32, item_id:int32, score:float32.
- `config.json`, `result.json`: конфигурация, версии, хеши, метрики, время и история качества обучения.

Оценка NDCG реализует официальные пессимистичные ничьи и равный вес лент; полный NDCG независимо проверяется `catboost.utils.eval_metric`. Итоговый файл проверяется на точное покрытие шаблона, типы, уникальность ключей и конечность score. Низкий score — допустимая оценка, преобразовывать его в вероятность не требуется.

Загрузите `submission.parquet` в разделе решений соревнования. Результат Public появляется после обработки организаторами; его нельзя получить из локальных данных. До отправки проверьте общий лимит пяти попыток команды за день. Baseline самостоятельно ничего не отправляет на ODS.

## Проверки

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m unittest discover -s catboost -p 'test_*.py' -v
```

Новые варианты этого метода сохраняйте отдельными конфигами и run-ID, с записью в experiments.md. Все преобразования для CatBoost остаются в этой папке.
