| **1. Кодировщик истории** | Каждое событие представить вектором объявления, эмбеддингами категории, типа и источника события, а также эмбеддингом его порядкового номера по давности. Спроецировать в 128 измерений. Обработать историю один раз на ленту двумя слоями Transformer с 4 головами и внутренним слоем ширины 256. | **2. Представление кандидата** | Объединить 128-мерные векторы пользователя и объявления, их покомпонентное произведение, косинусное сходство, эмбеддинг категории, `f1`–`f5` и процентиль каждого из этих пяти признаков внутри ленты. MLP с выходом 128 формирует запрос кандидата. Для отсутствующего вектора использовать нули и отдельный индикатор. |
| **3. Внимание кандидата к истории** | Один слой cross-attention, 4 головы. Запрос — вектор кандидата, ключи и значения — закодированные события. Так два объявления в одной выдаче могут опираться на разные эпизоды истории, а точный повтор объявления распознаётся даже при отсутствующем эмбеддинге. |

Применить один слой self-attention между всеми кандидатами ленты, 4 головы, ширина 128, **без позиционных эмбеддингов кандидатов**. Общая для всех кандидатов голова `128 → 64 → 1` с GELU выдаёт `score` в `float32`. Перестановка входных объявлений должна лишь переставить их оценки. |

### Обучение и критерий выбора

1. **Обучить на полном `train` с поправкой на позицию показа.** Для бинарной кросс-энтропии использовать логит `score + b[pos]`, где `b` — отдельная обучаемая скалярная поправка. Усреднять потери сначала внутри ленты, затем по лентам. В сам ранжировщик `pos` не передавать. Смысл поправки — дать модели отдельный параметр для связи между местом показа и действием. При предсказании использовать только `score`.
2. **Донастроить ту же сеть на случайно показанных лентах.** Отвести 22–23 сентября из размеченного `val` под дообучение, а 24 сентября заранее оставить для независимой проверки. На дообучении использовать попарную логистическую потерю LambdaRank внутри `feed_id`. Для пары «положительное — отрицательное» вес равен абсолютному изменению **полного NDCG** при обмене их текущих мест. Ошибка между первым и десятым местом тогда получает больший вес, чем такая же перестановка в хвосте. Стартовые параметры — AdamW, шаг `3e-4` на первом этапе и `3e-5` на втором, dropout `0,1`. [Даты и способ формирования выборок](https://ods.ai/competitions/avitotechrecsys2026/dataset)
3. **Измерить прирост на одних и тех же лентах.** До открытия результатов за 24 сентября зафиксировать число шагов дообучения. Посчитать разность NDCG модели и официального Transformer для каждой ленты, затем 95%-й доверительный интервал среднего прироста бутстрапом по пользователям. Нижняя граница выше нуля даст основание считать улучшение над бейзлайном воспроизводимым. Прямой критерий лидерства на проверенном снимке — результат сабмита **выше 0,3982555809 на Public**.
