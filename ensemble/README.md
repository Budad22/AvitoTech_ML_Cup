# CatBoost + MLP: локальный ансамбль

Ветка `bulat/catboost-mlp-ensemble`, отдельный worktree. Без обучения родителей,
test-инференса и submission. Исходная CatBoost-ветка не переключалась и её изменения сохранены.

Принятый кандидат: **EXP-ENS-002-r01**, стандартизация score внутри каждой ленты,
**25% CatBoost + 75% MLP**. Для постоянной ленты стандартизованный score равен нулю.
Конечный score переводится в float32 до оценки, включая официальное правило ничьих.

| Модель | Selection NDCG | Поздний control | Полная val |
| --- | ---: | ---: | ---: |
| CatBoost EXP-CB-024-r01 | 0,3651264374 | 0,3580054330 | 0,3637000641 |
| MLP EXP-024-history-stats-r01, эпоха 3 | 0,3684379277 | 0,3627265686 | 0,3672939136 |
| Ансамбль | **0,3695715972** | **0,3654341052** | **0,3687428366** |

Выбраны два заранее заданных способа калибровки (midrank и z-score) и по пять весов
0/0,25/0,5/0,75/1. Метод и вес выбирались только на selection. Порог принятия:
+0,001 к более сильному одиночному родителю (MLP). Решение сохранено до оценки
полной и поздней val; после них вес не менялся. Ранги не дали преимущества над MLP.

Полная Δ к MLP +0,0014489230; диагностический 95% bootstrap по user_id
[+0,00028034; +0,00258116]. Поздняя Δ +0,0027075365, интервал
[+0,00024413; +0,00544523]. Интервалы не учитывают выбор моделей/весов;
вся val использовалась исторически, независимая оценка не заявляется.

Конфиг: [configs/best.json](configs/best.json). Все точки сетки, метрики,
срезы и происхождение: [results/EXP-ENS-001-002.json](results/EXP-ENS-001-002.json).
Журнал: [../ensemble_exp.md](../ensemble_exp.md).

Команда выполненного опыта (повторная запись существующих результатов заблокирована):

```bash
../AvitoTech_ML_Cup/.venv/bin/python -u ensemble/blend.py \
  --source-root ../AvitoTech_ML_Cup \
  --inputs runs/ensemble/inputs
```

Повтор эксперимента требует новых EXP-ID/имён итоговых отчётов: существующие
результаты не перезаписываются. Входы находятся только в игнорируемой runs/:
MLP Parquet/JSON из коммита `4a1f9c8`, CatBoost Parquet/JSON из сохранённого EXP-CB-024.
Canonical val и её метаданные читаются из кэша исходной CatBoost-папки с проверкой hash.
Работа не требует весов моделей или доступа к GPU.

Тесты:

```bash
../AvitoTech_ML_Cup/.venv/bin/python -m unittest discover -s ensemble -p 'test_*.py' -v
```

На всех 1 389 971 val-кандидатах проверены точное воспроизведение сохранённой смеси
и инвариантность к перестановке кандидатов внутри лент. Нового онлайн-score нет.

## Дополнительные проверки EXP-ENS-003–006

| Проверка | Δ к текущей смеси по критерию принятия | Решение |
| --- | ---: | --- |
| Вес CatBoost по длине истории <64 / >=64 | +0,0001220096 на selection | Отклонить |
| Усреднение CatBoost seed42/seed17 | −0,0001566606 на selection | Отклонить |
| Метакорректор CatBoost, depth3, 53 дерева | +0,0005116507 на meta-tune | Отклонить |

Порог принятия +0,001. После каждого отклонения следующий опыт сравнивался
с прежней смесью EXP-ENS-002. Итоговый принятый кандидат остался прежним.
Третий эксперт MLP (EXP-ENS-006) не проверен: второго val-экспорта пока нет.

Метакорректор обучался на ранних 8076 лентах val, выбирал итерацию на следующих
3458 лентах; поздние 2889 лент оценены после фиксации решений. Полная val
и вся selection для этого опыта включают обучающие строки и не служат
независимой оценкой. Поздняя Δ метакорректора −0,0002384136.
Историческая val уже использовалась для выбора родителей.
