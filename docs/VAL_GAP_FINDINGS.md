# Почему local val выше оценки сайта: проверка 18 ноября

Пересчитаны сохранённые val-прогнозы, без обучения и без чтения test.
Результаты [reports/val_gap_audit.json](../reports/val_gap_audit.json),
скрипт [scripts/audit_val_gap.py](../scripts/audit_val_gap.py).

## Что проверено

На одинаковых1389971 кандидатах /14423лентах проверены уникальность и полное
совпадение ключей, finite scores, выравнивание меток. NDCG независимо рассчитан
NumPy и функцией metrics из закреплённого официального calculate_metrics.py
(включая её CatBoost-check). Совпадение лучше1e-10 у всех трёх моделей.
Исходная функция выполняется через AST без изменения; для Python3.9 предоставлен
эквивалент zip(strict=True) с проверкой размеров последовательностей.

| Модель | Ранняя selection11534 | Поздняя val2889 | Падение ранняя→поздняя |
| --- | --- | --- | --- |
| Слабый CatBoost015 | 0.3341035780 | 0.3308561424 | 0.0032474356 |
| CatBoost019 | 0.3531643039 | 0.3481853524 | 0.0049789515 |
| Сильный CatBoost024 | 0.3651264374 | 0.3580054330 | 0.0071210044 |

Более сильный из этих трёх методов теряет больше на поздней части. Это прямой
контрпример утверждению «более слабая модель обязательно должна терять больше».
Это наблюдение трёх сохранённых моделей, не универсальная закономерность.

## Состав лент сам меняет шкалу NDCG

| Свойство | Ранняя | Поздняя |
| --- | --- | --- |
| Среднее число кандидатов | 95.4825 | 99.9225 |
| Доля положительных кандидатов | 1.59875% | 1.51589% |
| Лент без положительных меток | 0 | 0 |
| Ожидаемый NDCG случайной перестановки | 0.2898863536 | 0.2852892934 |

Для ленты длины N с P положительными метками ожидаемый DCG равномерной
случайной перестановки — (P/N) * sum(1/log2(rank+1)); делим на IDCG данной
ленты и усредняем по лентам. Это точное математическое ожидание по известным
меткам val, а не обучение модели и не Monte Carlo.

Таким образом, даже без обученной модели ожидание NDCG падает на0.0045970602
между нашими ранней и поздней когортами. Причина здесь точно в составе лент
(N/P), а не в ошибке обученной модели. Из этого нельзя заключить, что ровно
такая же часть разницы с сайтом объяснена: его меток/когорт в этом аудите нет.
Случайную baseline нельзя механически вычитать для доказательства причин
просадки конкретной модели.

## Разница с сайтом не постоянна

Из журналов, где оценку сайта сообщил владелец (Submission ID и Public/Private
не зафиксированы; аудитор интерфейс соревнования не проверял):

| Модель | Полная val | Сайт | Разница |
| --- | --- | --- | --- |
| CatBoost015 | 0.3334531002 | 0.3250919360 | 0.0083611642 |
| CatBoost019 | 0.3521669947 | 0.3433693253 | 0.0087976694 |
| CatBoost024 | 0.3637000641 | 0.3521185292 | 0.0115815349 |
| MLP history_stats, исторический отчёт | 0.3672939136 | 0.3583967633 | 0.0088971503 |

MLP здесь заново не пересчитывался. Указанные значения сайта не подтверждают
постоянную поправку0.01 и не дают гарантии для следующего submission.

Вывод: общая ошибка формулы NDCG у проверенных val-прогнозов не обнаружена;
поздняя когорта хуже для всех трёх моделей, её состав отличается. Это предметное
основание исследовать перенос по времени, а не объявлять val сломанной.
Причина всего разрыва с сайтом не установлена. Для дальнейшей диагностики
сохранить Submission ID/точную часть leaderboard/хеши, сравнивать одинаковые
checkpoint и полный val, отдельно следить за поздней val. Разницу0.01 автоматически
не вычитать и метки test для подбора не использовать.

Пример повторения из рабочего дерева TabNet (prepared и scores вне Git):

```bash
PYTHONPATH=artifacts/metric-deps /PATH/TO/python scripts/audit_val_gap.py \
  --data /PATH/TO/artifacts/prepared-v1 \
  --prediction CB015=/PATH/TO/EXP-015-r01/val_predictions.parquet \
  --prediction CB019=/PATH/TO/EXP-019-r01/val_predictions.parquet \
  --prediction CB024=/PATH/TO/EXP-CB-024-r01/val_predictions.parquet \
  --official artifacts/official-baseline-review/calculate_metrics.py \
  --output reports/val_gap_audit.json
```

Polars1.14.0 для аудита установлен в отдельный artifacts/metric-deps через
`pip install --no-deps --target`, без изменения основного окружения.
