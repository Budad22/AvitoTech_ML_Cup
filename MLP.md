- Брать целые ленты вместе с их метками, кандидатами и историей. Не отбирать
  произвольные candidate-строки и не менять состав официальной val/test.

### Разбиение валидации MLP

**Полный запуск обучается на 100% train.** Малые опыты обучаются на выбранной
доле train. Число 80% относится только к разбиению отдельной validation-выборки:

| Часть | Для чего нужна | Текущий размер |
| --- | --- | --- |
| Train | Обновление весов модели | Весь train или фиксированная малая выборка |
| Selection | Выбор checkpoint и гипотез | Ранние 11 534 ленты, около 80% val |
| Control | Редкая итоговая проверка без подбора настроек | Поздние 2 889 лент, около 20% val |

Разделение нужно, чтобы выбор эпох, гипотез и весов ансамбля не подстраивался
под всю val. Поздний control показывает, переносится ли улучшение на следующий
период. Пропорция 80/20 — внутренний компромисс, не требование соревнования
и не доказанный оптимум. После фиксации checkpoint считать итоговую метрику
и экспортировать прогнозы на **100% официальной val**. Такая общая метрика уже
включает selection и не является полностью независимой проверкой. Если по
control тоже регулярно выбирать модели, он теряет роль отложенной проверки.

Официальная val содержит **14 423 ленты и 1 389 971 пару**. Текущая временная
граница — `1790249984`: selection имеет `timestamp < boundary`, control —
`timestamp >= boundary`. Использовать границу сохранённого протокола/checkpoint;
не подменять её новым случайным разбиением. Одинаковые timestamp не разрывать
между selection/control. Train+val допустим только как отдельный согласованный
финальный запуск без заявления о независимой оценке на прежней val.

Основная метрика — **полный NDCG с равным весом лент**. @10/@30 и loss —
дополнительные показатели. В текущем evaluator при равных score отрицательная
метка идёт первой; лента без положительных меток имеет NDCG=1.

EXP-027 использует прежнюю схему: до пяти эпох, patience=2, лимит малого опыта

### Автономные процессы и управление MLP

- Серверная очередь: Windows Scheduled Task `AvitoMLPSuite`, S4U,
  unlimited execution, IgnoreNew, скрытые процессы. Задача предотвращения сна —
  `AvitoMLPAwake`. Из другой ветки эти задачи не перезаписывать.
- Локальная очередь: прямой отсоединённый Python через WMI с
  `DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP`, stdout/stderr в файлы, без окна.
  PowerShell-обёртка в этой среде не подтвердила запуск; прямой Python подтвердил.
- Поддерживаемые сигналы остановки: `STOP_AFTER_CHECKPOINT` у опыта и
  `STOP_AFTER_CASE` у очереди. Перед применением проверить реализацию и область
  действия; останавливать только по указанию владельца.
- `--resume` продолжает тот же опыт с optimizer, RNG, курсором и бюджетом.
  `--init-from` загружает только веса в новый опыт.
- Для EXP-027 ожидаются 11/11 вариантов на ноутбуке и 12/12 на GPU

Для смешивания соединять модели по двум ключам, а не порядку строк. Веса
ансамбля подбирать на selection, поздний control использовать для проверки.

При новом экспорте сохранять Run-ID, эпоху, checkpoint SHA-256, commit/хеш кода,
data fingerprint, границу разбиения, NDCG и SHA-256 файла. Проверять schema,
null/NaN/Inf, уникальность и точное покрытие ключей нужного split. CLI `predict`
в текущем коде запускает test; для val нужен явный `evaluate(..., part='all',
output=..., split='val')` или `scripts/export_mlp_val.py`.
