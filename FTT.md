## Описания вариантов

| ID | Модель |
| --- | --- |
| FTT-001 | 2 блока, токен96, 4 головы, softmax-loss |
| FTT-002 | База + периодическое кодирование f1–f5,16 частот/sigma0,1 |
| FTT-003 | База + PLE16 для f1–f5 |
| FTT-004 | 3 блока |
| FTT-005 | Токен192 |
| FTT-006 | BCE вместо softmax-loss |
| FTT-007 | Внимание кандидата к 50 последним событиям |
| FTT-008 | Attention между кандидатами без позиций |

Порядок: 20 smoke-батчей всех моделей; все исправные на 0,78% до200 и800
шагов; база + два лидера + оставшийся вариант с лучшей динамикой до3200;
база + два лидера на вложенной выборке около5% с нуля до3200, при росте
хотя бы одного всем6400; база + победитель на seed43/44. Подтверждение на
остатке selection только после фиксации checkpoint. Нижняя95%-граница
bootstrap пользователей/seed должна быть положительной, как и минимум2/3
seed. Только тогда один полный запуск, если осталось минимум2ч.

Общий лимит8ч, отдельный опыт2ч. Фулл: максимум5эпох/2ч, валидация каждые
2000шагов и в конце эпох; early stopping после3 проверок без улучшения с6000шага.
На полном train последовательное чтение шардов; обучение с нуля, преобразования
чисел фиксируются по medium-train. Это отличается от случайного whole-feed order
малых опытов; фиксируется в конфигурации. Входы исключают target/pos/порядок кандидатов.
History recency — порядковый номер события: исходный контракт не содержит времени событий.

Кеш готовится отдельно на Q:, около5% включает малую выборку, поэтому точная
доля может превышать5%. Включены все кандидаты выбранных шардов. Официальная
val кешируется полностью, late control не оценивается до финала. Граница по
timestamp на80% val, одинаковые timestamp остаются вместе. Fast-selection —
2000 фиксированных случайных лент; confirmation — остальные selection.
Отбор не использует метки control. Требуется больше данных для вывода о потолке.

Серверный снимок: `Q:/AVITOCUP/experiments/FTT-NIGHT-001/code`.
Статус/ledger/report/checkpoint находятся рядом. JSON-статус содержит heartbeat,
устройство, модель, шаг, бюджет и ошибки. Контроллер не зависит от SSH.

```powershell
python scripts/status.py --host 26.27.122.189 --user bl1tz2200
python scripts/status.py --host 26.27.122.189 --user bl1tz2200 --logs 50
python scripts/status.py --host 26.27.122.189 --user bl1tz2200 --json
```

`--watch 2` повторяет снимки; Ctrl+C завершает только просмотр. Один CLI вместо API
сокращает инфраструктуру. Веса/данные/секреты не добавляются в Git.
