# AvitoTech_ML_Cup

Решение соревнования [«Персональное ранжирование | Avito ML cup 2026»](https://ods.ai/competitions/avitotechrecsys2026).

- [План работы двух участников](PLAN.md): задача, ответственность, этапы и правила сравнения.
- [Переносимые принципы экспериментов](principes.md): инструкция для другой ветки или чата, быстрый локальный отбор и автономное обучение на CPU/GPU.
- [Журнал экспериментов](experiments.md): гипотезы, запуски, результаты и решения.
- [Эксперименты и особенности MLP](MLP.md): простые описания моделей, результаты, настройки, команды и детали реализации.
- [Val-прогнозы MLP для ансамбля](ensembles/mlp/README.md): Parquet сырых logits на всей официальной val и JSON с происхождением checkpoint.
- [Быстрая проверка гипотез](docs/MLP_SCREEN.md): 11 вариантов на 0,78% и 1,56% train, затем полный запуск победителя.
- [Первичный аудит данных](reports/DATA_AUDIT.md): измеренные особенности, ограничения и подготовка для разных моделей.
- [Общий слой данных](docs/DATA.md): подготовка, маски и чтение целых лент для модельных веток.
- [Автономная очередь MLP](docs/MLP_SUITE.md): 11 последовательных абляций, мониторинг и восстановление.

Оба участника работают с AI-ассистентами и самостоятельно проводят модельные эксперименты. Конкретные архитектуры заранее не закреплены: подходы выбираются по результатам проверок.

Перед любым пушем в GitHub владелец просматривает изменения и явно одобряет отправку.
