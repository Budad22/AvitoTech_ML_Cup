# Монитор обучения

Страница для браузера — [Монитор обучения](http://server.taild49777.ts.net:8787/). Обновляется каждые 15 секунд и показывает время по Москве.

На сервере Ярика сервис слушает Tailscale-адрес `100.91.51.27:8787`. Задача Windows `Budad22TrainingMonitor` запускает его при загрузке. Рабочая папка — `Q:/AVITOCUP/training-monitor`.

- `GET /api/current` возвращает активные эксперименты, этап, прогресс, ETA этапа и следующие этапы этого запуска.
- `GET /api/queue` возвращает будущие эксперименты в порядке плана и отслеживаемые задачи со статусом Windows Queued. Для запланированного запуска поле `after` указывает предшественника. Возможные состояния — `waiting`, `blocked`, `awaiting_start` и `queued`.
- `GET /api/status` объединяет текущие запуски, очередь и результаты завершённых экспериментов.

Время указано в UTC. Снимок обновляется при запросах максимум раз в пять секунд. Прогноз длительности рассчитывается по средней скорости активного этапа. После трёх минут без записи прогресса ETA скрывается.

Для учёта следующего обучения добавить запись в массив `jobs` файла `jobs.json` на сервере. Поля совпадают с существующими записями. Чтобы оно появилось в очереди заранее, указать `after` с ID текущего эксперимента и отдельную рабочую папку. Порядок записей задаёт порядок отображения плана. Изменения конфигурации применяются при следующем обновлении. Задания запускает настроенный отдельно планировщик; API предоставляет доступ на чтение.

Для запуска вручную использовать `python -B server.py --config jobs.json --bind 100.91.51.27 --port 8787`.
